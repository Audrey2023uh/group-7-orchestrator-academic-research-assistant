# Interview Story — Cascade Failure Guardrail

Malformed upstream state—an empty analysis payload without `paper_id`—caused the reporter path to throw `KeyError` and abort the run. Across twenty deterministic trials the unguarded downstream path crashed every time. Inserting an explicit sanitization node that checks invariants before reporting converted those crashes into rollback responses that set a rejection flag for coordinator-driven recovery. After the guardrail, downstream crashes dropped to zero and rollback success reached one hundred percent on the same malformed inputs. Capturing crash counts and rollback rate in `metrics.md` made the failure mode interview-ready: we can show that validation is not a courtesy check but a hard gate that prevents one bad worker payload from cascading through the graph.
