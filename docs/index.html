Interactive multi-agent research workflow with persistent memory

This landing page is static documentation hosting. The live product is a Python FastAPI service that runs the coordinator-driven LangGraph graph (analyze → 20 independent reviews → validate → meta-analysis) with short-term session memory and long-term SQLite research memory.

Multi-agent runtime

Coordinator + Analyzer + Independent Reviewer × N + Validator + Reporter with six guardrails.

Persistent memory

Server-side SQLite stores sessions, findings, decisions, and agent outputs across restarts.

User controls

View, pin, approve, delete individual items, or clear all memory for the current user.
